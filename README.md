# 🛍️ Nostra E-Commerce Website

Nostra is a **responsive men's clothing e-commerce website** designed with a clean, modern, and user-friendly interface. The website allows users to explore clothing collections, filter products, search for products, and contact the website through a simple contact form.

This project was developed using **HTML, CSS, and JavaScript** to practice responsive web design and JavaScript-based interactivity.

## 📌 Pages

### 🏠 1. Home Page

The Home page provides an attractive introduction to the Nostra clothing brand.

**Sections included:**

* 🎁 Offer Suggestion section with close icon
* 🧭 Navigation links, responsive sidebar navigation links
* 🖼️ Impressive header/hero section
* 🏷️ Brands section
* ℹ️ About Us section with icons
* 🆕 New Arrivals section
* ❤️ Most Wanted section
* 📢 Promotional offer/ad section
* 📧 Newsletter section
* 🔗 Footer section

### 👕 2. Collection Page

The Collection page allows users to explore and find products easily using filtering and search functionality.

**Features included:**

* 🎁 Offer Suggestion section
* 🧭 Navigation links, responsive sidebar navigation links
* 🔎 Product search functionality
* 🎯 Filter functionality
* 👕 Shirt collection display
* 📧 Newsletter section
* 🔗 Footer section

The filtering and search features make it easier for users to find products based on their preferences.

### 📞 3. Contact Us Page

The Contact Us page provides a simple way for users to get in touch.

**Features included:**

* 🧭 Navigation links
* 📝 Contact form
* 🔘 Submit button
* 📧 Newsletter section
* 🔗 Footer section
